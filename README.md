# Swahilipot Hub Management System (SHMS)

Complete modular scaffold for Swahilipot Hub operations: accounts, RBAC, equipment, projects, subscriptions, Wi-Fi, feedback, file transfer, FM monitoring, calls, radio, news, videography, dashboard, Docker, Nginx, CI, Swagger, PostgreSQL, Redis, and MinIO-compatible file storage.

## Run
```bash
cp .env.example .env
docker compose up --build
```
Backend: http://localhost:8000/api/v1/
Swagger: http://localhost:8000/api/docs/
Frontend: http://localhost:5173/
